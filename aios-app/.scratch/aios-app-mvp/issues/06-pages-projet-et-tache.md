# 06 — Pages projet et tâche

**What to build:** L'utilisateur tape un projet ou une tâche et arrive sur sa page complète : tout le contexte du fichier, lisible, avec un retour explicite. Depuis la page, il ouvre le fichier dans Obsidian quand il veut éditer le corps du texte.

**Blocked by:** 03 — Vue Global, projets.

**Status:** complete

- [x] Page projet : objectif, statut, priorité, dates, tâches ouvertes, notes liées, journal
- [x] Le statut du projet est affiché avec un marqueur de lecture seule explicite
- [x] Page tâche : contexte, solution proposée, critères de succès, journal, et les quatre champs éditables
- [x] Retour en arrière explicite sur les deux pages, qui ramène à la position précédente
- [x] Un lien ouvre le fichier correspondant dans Obsidian
- [x] Les wikilinks du corps sont rendus comme des liens ; un lien mort est signalé comme tel et jamais ignoré silencieusement
- [x] Les deux pages sont accessibles depuis le rail des projets en cours, les listes de la vue Global et les résultats de recherche
