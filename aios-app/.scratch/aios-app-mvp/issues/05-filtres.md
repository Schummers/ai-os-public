# 05 — Filtres de la vue Global

**What to build:** L'utilisateur restreint ce qu'il voit avec trois filtres visibles en permanence et les autres derrière un bouton. Il sait toujours combien de filtres sont actifs, et ses filtres survivent au passage entre projets et contenus.

**Blocked by:** 03 — Vue Global, projets.

**Status:** complete

- [x] Barre visible : statut, priorité, échéance ; le reste derrière un bouton de filtres
- [x] Le bouton de filtres porte un compteur quand des filtres secondaires sont actifs
- [x] Filtre sur l'autonomie disponible, permettant d'isoler les tâches délégables
- [x] Les filtres persistent quand on bascule entre Projets et Contenus
- [x] Les filtres se réinitialisent quand on passe de Global à Daily
- [x] La barre reste utilisable à 390px, sans déborder ni écraser le contenu
- [x] L'état des filtres est reflété dans l'URL, pour qu'un rechargement ne le perde pas
