# 12 — Recherche globale

**What to build:** L'utilisateur tape trois lettres depuis n'importe quel écran et retrouve la tâche, le projet, la note ou le contenu qu'il cherche, plus vite qu'en naviguant. Les résultats sont groupés par type pour qu'il ne confonde pas une note et une tâche du même nom.

**Blocked by:** 03 — Vue Global, projets.

**Status:** complete

- [x] La recherche est atteignable en un tap depuis tous les écrans, à l'extrême droite de la barre du haut
- [x] Les résultats se filtrent dès la première frappe
- [x] La recherche porte d'abord sur les titres et le frontmatter des entités
- [x] Les résultats sont groupés par type : tâches, projets, contenus, notes, sources, goals
- [x] Chaque résultat montre de quoi il dépend (projet parent, goal, statut) pour être identifiable sans l'ouvrir
- [x] La recherche plein texte dans le corps des fichiers est un second geste explicite, jamais automatique
- [x] Les dossiers du calendrier et du cache d'agent sont exclus par défaut
- [x] Un résultat mène à la page de détail correspondante
